Overview

Financer helps you track budgets and expenses. This policy describes what data is collected and how it is used.

Data We Collect

  • Account data: email only (if an account is created).
  • Financial records you enter: budgets, categories, transactions.
  • Diagnostics and basic device info for crash reporting.

How We Use Data

  • Store and sync your finance data securely.
  • Provide features like charts, reports, and backups.
  • Improve reliability and user experience.

Security

We use industry-standard encryption in transit and at rest where applicable.
